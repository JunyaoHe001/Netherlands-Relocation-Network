# Documentation

This directory contains methodological, technical, and publication documentation that is separate from the deployable website.

Planned documents include:

- dataset construction and municipal-boundary harmonisation;
- iterative proportional fitting and constraint diagnostics;
- validation and robustness procedures;
- analytical model specifications;
- public atlas architecture and visual-interpretation notes;
- release and citation procedures.

The deployable static website is stored under [`website/`](../website/).
