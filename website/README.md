# Website

This directory stores the maintained source and documentation for the project website. The deployed static files are kept on the `gh-pages` branch so that publication artifacts remain isolated from research code, notebooks, and data releases on `main`.

## Live pages

- Project page: <https://junyaohe001.github.io/Netherlands-Relocation-Network/>
- Interactive atlas: <https://junyaohe001.github.io/Netherlands-Relocation-Network/atlas/>

The atlas is a generated public data product. Changes should be built and validated locally before replacing the corresponding files on the deployment branch.
