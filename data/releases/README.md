# Versioned data releases

Create one subdirectory per formal dataset version, for example `v1.0.0/`.

Each release directory should contain or link to:

- a release-specific README;
- data files or an archived-download location;
- a data dictionary;
- provenance and methods metadata;
- reconstruction and validation summaries;
- a checksum manifest;
- a licence notice;
- the exact citation for that version.

Do not replace an archived release in place. Corrections should be issued under a new semantic version and documented in a changelog.
